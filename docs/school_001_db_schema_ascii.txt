                                    SCHOOL_001_DB
                         Multi-Tenant School Bus Tracking Schema
===========================================================================================

Verified against the live MySQL database school_001_db (information_schema), the
models under app/Models/Tenant and the services under app/Services.

LEGEND
-------------------------------------------------------------------------------------------
  PK   primary key             FK   real foreign key constraint in MySQL
  UQ   unique index            UQ*  composite unique key, see the box

  created_by_id / updated_by_id exist in every tenant table and are used by
  TenantModel::createdBy() and ::updatedBy().  MySQL has NO foreign key on those
  two columns, so they are logical links only and carry no (FK) tag here.

  student_route_assignments has NO vehicle_id column.  A student is tied to a
  bus through student_route_assignments.route_id -> active_trips.vehicle_id.

  Arrows point from the "many" side to the "one" side where the reading is
  clear.  RELATION SUMMARY at the end of this file is the authoritative list.

  CAREFUL  live_vehicle_locations.active_trip_id has no UNIQUE constraint,
  so a trip may have several live location rows.  The Eloquent model
  ActiveTrip::liveVehicleLocation() declares hasOne, which assumes one.
  The database permits many.  Treat that as a code/schema mismatch.

NOTE  There is deliberately NO "VEHICLES -> STUDENT_ROUTE_ASSIGNMENTS" line.
      That table has no vehicle_id column.  The schema constraint names
      student_vehicle_assignments_student_id_foreign,
      student_vehicle_assignments_route_id_foreign and
      student_vehicle_assignments_stop_id_foreign are leftovers from an
      earlier table name; they are live constraints on the current table
      and point at students, vehicle_routes and stops respectively.


FOREIGN KEY MAP
===========================================================================================
students.parent_id              -> parents.id
students.class_section_id       -> class_sections.id
stops.route_id                  -> vehicle_routes.id
driver_route_assignments.driver_id  -> admin_and_drivers.id
driver_route_assignments.vehicle_id -> vehicles.id
driver_route_assignments.route_id   -> vehicle_routes.id
student_route_assignments.student_id -> students.id
student_route_assignments.route_id   -> vehicle_routes.id
student_route_assignments.stop_id    -> stops.id
active_trips.driver_id          -> admin_and_drivers.id
active_trips.vehicle_id         -> vehicles.id
active_trips.route_id           -> vehicle_routes.id
live_vehicle_locations.vehicle_id    -> vehicles.id
live_vehicle_locations.active_trip_id -> active_trips.id
vehicle_location_history.vehicle_id     -> vehicles.id
vehicle_location_history.active_trip_id -> active_trips.id

Eleven of the sixteen use ON DELETE SET NULL (their column is nullable
with a NULL default).  The remaining five use ON DELETE RESTRICT.
Every one of the sixteen is ON UPDATE RESTRICT.

  ON DELETE SET NULL:
    students.parent_id
    students.class_section_id
    stops.route_id
    student_route_assignments.route_id
    student_route_assignments.stop_id
    driver_route_assignments.route_id
    active_trips.driver_id
    active_trips.vehicle_id
    active_trips.route_id
    live_vehicle_locations.active_trip_id
    vehicle_location_history.active_trip_id

  ON DELETE RESTRICT:
    student_route_assignments.student_id
    driver_route_assignments.driver_id
    driver_route_assignments.vehicle_id
    live_vehicle_locations.vehicle_id
    vehicle_location_history.vehicle_id

COLUMN VALUES AND DEFAULTS
===========================================================================================
vehicle_routes.trip_type      Morning | Afternoon | Evening | Special Trips
                              (validated in RouteController; varchar(25))
active_trips.trip_status      started | finished | cancelled
                              (validated in ActiveTripController)
                              DB default is "scheduled", which the controller
                              does not accept, so a row is never left at it
admin_and_drivers.user_role   super admin | transport admin | data entry staff
                              | cab drivers | cab assistant
                              (AdminAndDriverService::USER_ROLES; varchar(255),
                              stored as free text, not an enum)
notifications.notification_type  default "general"
notifications.channel            default "app"
                              No controller, service or route writes to this
                              table.  It currently holds 0 rows.

latitude / longitude         decimal(10,7); latitude -90..90, longitude
                              -180..180 (controller validation)
speed                         decimal(8,2), >= 0
heading                       decimal(8,2), 0..360
ignition_on                   tinyint(1) NOT NULL DEFAULT 0
is_active                     tinyint(1) NOT NULL DEFAULT 1
stop_order                    int unsigned NOT NULL DEFAULT 0
section                       varchar(255) NOT NULL DEFAULT ""
